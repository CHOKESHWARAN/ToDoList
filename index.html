Project Overview

The To-Do List application is a simple reminder system that helps users manage their daily tasks. Users can add, complete, edit, and delete tasks. Task data is stored on the server in a SQLite database, so every change is persisted centrally when a task is added or updated. This project demonstrates basic CRUD operations using HTML, CSS, JavaScript, Node.js, Express, and SQLite.
